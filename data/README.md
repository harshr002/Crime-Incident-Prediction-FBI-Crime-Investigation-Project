# Dataset

Place the crime dataset here before running the notebook locally:

- `Train.xlsx` (or `Train.xlsb`)

The notebook (`../Crime_Prediction_Project.ipynb`) looks for `Train.xlsx` / `Train.xlsb`
in the project root or this `data/` folder. On Google Colab, upload the file with the
file browser instead.

Source: City of Vancouver / VPD open crime data (1999–2011).
